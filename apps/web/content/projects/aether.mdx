AETHER is a Rust foundation for a local-first desktop agent. Its current scope includes workspace and core agent interfaces, filesystem tools, permission checks, SQLite-backed memory, indexing and search helpers, Obsidian helpers, a daemon facade, and a CLI.

The project keeps the agent's foundations explicit: local workspace access, stored context, and clear permission boundaries come before adding more autonomous behavior.
