## Why I made it

Parker exists to remove friction from screen capture. A selected region should become usable text, a spreadsheet-ready table, a QR destination, or a shareable clip without sending private screen content to a cloud service.

## How it is built

The Rust desktop app listens for global hotkeys and keeps its controls in the Windows notification area. Smart Capture runs a single Tesseract TSV pass to classify and reconstruct OCR output, with a higher-cost QR retry only when the fast path finds nothing. It preserves code indentation, reconstructs tables as TSV, and puts each result directly on the Windows clipboard.

Region Recording excludes the cursor and Parker's own overlays, writes a resilient temporary capture, then checks NVIDIA, Intel, and AMD encoders before falling back to x264. FFmpeg produces a compatible fast-start H.264 MP4 and copies it as a file clipboard entry.

## Current progress

Smart capture, region recording, tray controls, settings, per-user installation, encoder fallback, self-update, and release packaging are implemented. Current limitations are documented in the repository: OCR quality depends on source material, audio capture is opt-in, and some protected or hardware-overlay video cannot be captured.
