TradePilot converts a static landing-page concept into a structured Next.js App Router project.

The build keeps the original dark, futuristic revenue-intelligence direction while separating the page into reusable sections and centralizing copy in a small data module. It uses TypeScript, Tailwind CSS, and Lucide icons.
