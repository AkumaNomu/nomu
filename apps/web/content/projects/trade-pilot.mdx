## Why I made it

TradePilot started as a static landing-page concept. I rebuilt it to turn a visual direction into a maintainable application rather than leaving it as a one-off HTML mockup.

## How it is built

The project uses Next.js App Router, React, TypeScript, Tailwind CSS, and Lucide icons. I split the page into focused sections for navigation, the hero, platform, intelligence, solutions, and footer, while keeping page copy in a single data module instead of scattering it across components.

## Current progress

The landing page rebuild is complete. The repository now provides a reusable, locally runnable Next.js implementation of the original dark revenue-intelligence direction.
